TRAINING MODULE 3

Fine-Tuning Is Not a Knowledge Tool

This module spans three phases. Phase 1 probes the base model on a knowledge-gap topic — watch it hedge or fail. Phase 2 happens off-platform: groups author Alpaca-format Q&A pairs in VS Code and the facilitator runs a live QLoRA fine-tune on the GPU rig (~10 minutes). Phase 3 compares base vs fine-tuned side-by-side. The lesson: fine-tuning shapes behaviour, not facts.
